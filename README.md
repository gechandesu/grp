# Access to the UNIX Group Database

`grp` module provides thread-safe access to the UNIX user group database.

See [group(5)](https://man7.org/linux/man-pages/man5/group.5.html),
[getgrent(3)](https://man7.org/linux/man-pages/man3/getgrent.3.html) and
[getgrnam(3)](https://man7.org/linux/man-pages/man3/getgrnam.3.html) for details.
